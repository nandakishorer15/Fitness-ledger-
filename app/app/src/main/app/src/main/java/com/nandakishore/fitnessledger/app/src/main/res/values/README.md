# Fitness Ledger Native

Native Android starter for a personal fitness, food, activity and weight-loss tracker.

## Current build
- Jetpack Compose UI
- Android Health Connect step permission
- Today's aggregated step count
- Offline UI foundation

## Planned modules
Food database, calories/macros, weight history, GPS running, progress charts, coaching and Strava OAuth.

## Build
GitHub Actions installs Gradle 8.7 and runs `gradle assembleDebug`.
